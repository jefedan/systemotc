🔍Verificar Cabeceras de Seguridad

Haz clic para verificar...
🖱️Protección Clickjacking

La cabecera X-Frame-Options: DENY y CSP frame-ancestors 'none' bloquean la carga en iframes.

Intento de iframe: Si intentas cargar esta página en un iframe, el navegador la bloqueará automáticamente.
// Cabeceras que protegen: X-Frame-Options: DENY Content-Security-Policy: frame-ancestors 'none' // Efecto: ningún sitio externo puede embeber // esta aplicación en un <iframe>
🔗Subresource Integrity (SRI)

Verifica integridad de recursos externos via CDN con hashes criptográficos.

<!-- ✅ CON SRI — seguro --> <script src="https://cdn.example.com/lib.js" integrity="sha256-abc123..." crossorigin="anonymous"> </script> <!-- ❌ SIN SRI — vulnerable --> <script src="https://cdn.example.com/lib.js"> </script> <!-- Si el CDN es comprometido, ejecuta código malicioso -->
