⚠️SQL Injection — Modo Inseguro vs Seguro
Elige un modo y ejecuta...
📖Cómo funciona
# ❌ INSEGURO — concatenación directa query = f"SELECT * FROM users WHERE username = '{input}'" # Con input: admin'-- # Resultado: WHERE username = 'admin'--' # El -- comenta el resto → bypass total
# ✅ SEGURO — SQLAlchemy ORM user = User.query.filter_by(username=username).first() # El ORM usa parámetros vinculados automáticamente # Input se trata como DATO, nunca como código
🛡️ Esta app usa SQLAlchemy ORM + Prepared Statements en todas las consultas
